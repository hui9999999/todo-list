# 我的待办清单 📝

一个纯前端、零依赖的待办清单（Todo List）单页应用，所有功能都在一个 `index.html` 文件里，双击即可使用。

## ✨ 功能特性

- ✅ 任务的新增、编辑、完成、删除，支持子任务（无限层级）
- 🎯 优先级（高 / 中 / 低）、到期时间、进度条、专注计时
- 🔁 周期任务（每日 / 每周 / 每月）
- 📅 日期导航与日历选择器，按天查看任务
- 📊 统计面板：完成率环、7 日趋势图、分类图表
- 🧭 侧边工作台：任务、统计、AI、花田、垃圾站和数据管理按工作区切换，任务详情从右侧抽屉打开
- 🌤️ 天气展示、🌻 随时间变化并随完成任务成长的「我的花田」场景
- 🎨 多主题配色（含暗色模式）+ 任务粒子特效
- 💾 数据本地存储（localStorage），支持导入 / 导出备份

## 🚀 使用方式

无需安装任何依赖，直接用浏览器打开 `index.html` 即可；花田图片已经内嵌，换电脑时只需复制这个 HTML 文件。任务数据仍保存在浏览器本地，跨电脑迁移请先在「数据管理」中导出 JSON，再在新电脑导入。也可以部署到 GitHub Pages / 任意静态服务器。

## 🛠️ 技术栈

原生 HTML + CSS + JavaScript，单文件实现，无框架、无构建工具。
