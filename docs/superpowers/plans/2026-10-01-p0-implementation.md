# P0 基础与迁移实施计划

依据：`../specs/2026-10-01-ai-todo-v2-design.md`。用户于 2026-10-01 指示按 2.0 方案逐步实现，视为批准方案默认技术选型。

1. 保留 1.0 快照和根入口，建立 `codex/ai-todo-v2` 分支。
2. 建立 Vue 3 / TypeScript / Vite / Router / Pinia / Element Plus 前端，以及 FastAPI / SQLAlchemy / Alembic 后端。
3. 使用真实 PostgreSQL + pgvector；独立迁移角色和受限应用角色，私有业务表启用 RLS，事务内设置用户范围。
4. 实现邮箱注册、验证、会话、退出、密码重置；开发邮件交由本地 Mailpit，生产要求配置 HTTPS 与 SMTP。
5. 实现工作／生活／未分类任务、子任务、版本冲突、垃圾站、今日安排，以及同事务事件与快照。父任务有未完成子任务时禁止完成，避免隐式批量写入。
6. 实现 1.0 JSON 导入预览、字段与日期校验、重复导入控制、ID 映射、原始时间保留；提供版本化备份和兼容 1.0 导出。
7. 完成中文响应式操作界面，无 API Key 也能操作任务；2.0 不引入花田或语音。
8. 以 PostgreSQL 集成测试验证隔离、认证、CSRF、关系、历史、冲突与迁移；构建前端并验证浏览器核心流程。

出口：双用户不能读取或关联彼此任务；导入数量、关系、状态、时间和备注对账；手动日常操作完整。P1～P4 不在本阶段宣称完成。公开发布与邮件投递、备份恢复演练留到 P4。
