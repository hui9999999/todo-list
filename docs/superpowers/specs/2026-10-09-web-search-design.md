# 小狒免费联网搜索方案（已确认）

## 已确定的需求

用户要求云端小狒增加联网搜索，选择开启联网后由小狒按问题需要自动搜索，并选择先做免费、无需密钥的版本。保留当前 DeepSeek 对话模型。搜索由服务器实际执行，回答附可点击来源，搜索请求对象不作为聊天正文展示。

## 接入选择及实际验证

选择 Bing 公开搜索 RSS 入口 `https://cn.bing.com/search`，查询参数使用 `q`、`format=rss`，服务端解析标准 RSS 条目中的标题、链接与摘要，无需新增账号或密钥。

2026-10-09 从生产 API 容器进行公开资料的只读探测：英文 Python 文档查询返回 10 条，其中包含 Python 官方网站，并有摘要；中文若干查询返回空结果或相关性较弱。此入口适合作为免费基础版本，不能承诺与完整商业搜索 API 同等的中文召回、新闻时效或稳定性。针对空结果，小狒可以尝试更简洁或英文关键词，但不能将空结果解释成网上不存在资料。

备选 Exa 官方提供免登录、免密钥且限流的 MCP 搜索，但当前生产容器连接超时；暂不纳入默认调用链。独立商业搜索 API 需要凭据，与本次免费目标不符，后续有需要再接入。

## 使用流程

1. 在助手输入区显示“联网搜索”开关，默认关闭；按账号在当前设备记住选择，退出账号不会把另一账号的选择带入。用户主动开启后，后续消息可以按需搜索。
2. 开启时，模型可提交结构化搜索关键词。最新消息明确要求搜索时应执行真实搜索；纯任务管理、普通聊天及已有账号资料查询无需联网。
3. 搜索中显示“正在联网搜索”；收集真实来源、标题与摘要后交回当前对话模型生成回答。
4. 回答下方以独立来源列表展示编号、标题和站点，可点击打开；来源由服务器的搜索结果生成，模型只能引用已有来源编号。
5. 来源与对应回复一并恢复，切页、刷新、查看历史后仍可见。旧消息没有来源时保持原展示。
6. 超时、限流、无结果时说明真实情况；不以模型旧知识伪装搜索成功。联网关闭时不发出任何搜索网络请求。

## 后端接口与执行边界

- `MessageInput` 增加默认 `false` 的 `web_search_enabled`。发送时固化到运行的 `model_binding` JSON，兼容旧客户端，无数据库迁移；重复幂等键必须核对联网选项，避免请求被错误复用。
- `AgentOutput` 增加受限的 `web_search` 请求数组，关键词非空、长度上限 200；搜索阶段与回答提案、导出和记忆候选分开。工具模式及 JSON 模式复用相同校验。
- 独立的搜索模块只访问预设 Bing HTTPS 入口，使用已有 httpx，无任意 URL 抓取或新增服务进程。校验响应大小、XML、条目数量，清理摘要中的 HTML，去重链接。
- 每次运行最多两次搜索，每次最多五条结果；有空结果时可通过一次补充关键词查询改进。调用超时及响应体上限独立于模型限制，继续遵循现有取消和运行截止时间。
- 只发送本轮必要的搜索关键词，不向搜索入口提交整段对话、附件、任务列表或认证凭据。资料和网页摘要只作为证据，不授予写操作权限。
- 公开链接只接受合法 HTTP(S) 地址，拒绝认证信息、脚本协议与本地地址；不自动加载来源图片，不执行来源 HTML。
- 搜索状态和结果使用现有 `RunEvent` 留存，附回复消息 ID。消息读取接口返回与消息对应的来源，执行期间的状态接口支持恢复搜索进度。模型不能自行生成来源链接。
- 联网关闭、未取得来源或遇到服务错误时，禁止宣称搜索成功；有来源的回答注明基于搜索摘要，不能声称已阅读全文。来源日期缺失时不猜发布日期。
- 本次搜索入口不需要付费 API 或密钥；DeepSeek 生成关键词、处理搜索结果及回答仍按已有模型账号计费，不承诺整段聊天免费。

## 前端范围

主要修改 `frontend/src/components/AIAssistant.vue`、聊天类型与会话偏好存储。沿用现有输入区和消息布局，手机窄屏不得挤掉输入或发送按钮。来源链接使用独立组件，避免将任意网页 HTML 或 Markdown 直接注入页面。安卓和桌面客户端沿用相同 API，恢复逻辑兼容当前原生状态轮询。

## 验收

- 搜索模块：标准 RSS、空结果、错误状态、超时、过大响应、畸形 XML、HTML 摘要和不安全链接。
- 真实聊天执行路径：联网关闭无搜索；开启且需要时真实调用；空结果补充查询；来源编号与服务器结果一致；取消后不再发布结果；搜索资料不能绕过任务确认；两种模型传输方式均可执行搜索。
- 隔离与恢复：重复幂等选项冲突，其他账号不能读取来源，旧消息兼容，切页/刷新恢复来源，退出清理账号偏好。
- 手机与桌面：开关、正在搜索、错误提示、来源链接、刷新恢复、无横向溢出。
- 云端：用公开的中英文测试问题进行真实搜索和模型回答验证，不改写用户现有任务与对话；核对服务健康及运行代码哈希，保留部署前备份。
