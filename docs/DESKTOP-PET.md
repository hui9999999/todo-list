# 小狒 Windows 桌宠

## 本次接入范围

用户已确定 Windows 桌面悬浮、陪伴、拖动、专注联动、完成庆祝，并可通过桌宠聊天管理任务；其他交互按本方案实现。

采用 Electron 透明置顶窗口承载桌宠，独立聊天窗口复用现有 Vue 应用和 AI 任务操作预览。聊天窗口关闭时隐藏并保留会话，宠物和托盘继续运行。默认显示、无声音，位置和外观偏好保存在当前 Windows 用户的应用数据目录；不默认写入开机启动。右键与托盘提供隐藏、静止、调整大小、打开助手/工作台/设置、退出。

桌宠与聊天共用 Electron 登录会话。浏览器默认使用免安装的网页小狒；Windows 桌面版仍可从网页手动打开，也可在偏好设置中开启自动启动。首次需允许浏览器打开小狒，并在桌宠确认绑定。已绑定的同一浏览器再次打开时直接复用绑定，不额外打开聊天窗口，也不清空聊天草稿。浏览器可能阻止无用户操作的外部协议启动，此时可点击“打开 Windows 桌宠”或“打开桌宠设置”；首次安装桌面版请先运行启动器注册协议。

网页与当前浏览器绑定的桌面版互斥。网页确认隐藏后，桌面版才显示；桌面版退出后网页在约 12 秒内恢复。两边使用短期显示许可，断网时先隐藏失去许可的角色，以避免同时出现。其他电脑或其他浏览器的登录不会影响当前绑定。桌宠中心同样在桌面版运行时隐藏角色预览；Windows 聊天窗口内不显示额外的网页小狒。桌面程序升级后需退出并重新启动以加载交接逻辑。

绑定后，网页切换账号或退出，桌宠会在约 2 秒内跟随，重新读取该账号已有的模型、任务和专注数据，重启后保持绑定。绑定前仍可在桌宠窗口独立登录。不读取其他浏览器的 Cookie，也不传递密码或模型 Key；绑定票据 60 秒有效且只能使用一次，桌宠同步凭据由 Windows 加密保存。网页登录会话过期、密码重置或账号删除后停止沿用该账号。首次读取旧完成记录不庆祝，换账号或退出后清空旧状态。任务操作沿用预览、确认、撤销流程。

外观保留两版，均保留绿色围巾、勾号、叶子尾巴和腮红。2D 原版读取原角色与动作图集，使用完整角色轮廓和真实中间姿态播放；图集格子外的脚尖通过扩大读取范围保留，原 PNG 不改动。3D 立体版使用完整奶油色黏土猫模型，肩、肘、髋、膝使用真实骨骼与蒙皮，同一个身体承载全部动作；手保持在腰部以上，散步由双脚交替支撑。3D 支撑脚相对角色的速度抵消桌面移动速度，抬脚后再向前摆动，方向改变时连续转身。两版共用动作调度，切换经过收势、起身或坐下，庆祝包含下蹲、起跳和落地。拖动位移立即响应。桌面与工作台共用版本选择与播放入口，无需在线模型服务。原生窗口保证不因拖动或显示器变化而遗留在屏幕外；空白区域透传鼠标。

## 启动

双击项目根目录的 `启动小狒.cmd`，或运行 `scripts/start-desktop-pet.ps1`。启动器复用已运行的工作台服务；首次安装 Electron 依赖。直接启动桌宠可在 desktop 目录运行 `npm start`，首次默认连接 `http://localhost:5174`。网页启动链接携带其工作台地址，桌宠选择对应服务并记住地址，后续重启沿用；可通过 `WORKBENCH_URL` 显式配置默认地址。接收不同工作台的启动链接时先重启切换连接，再验证该服务签发的票据。协议链接仅允许本机、当前云端部署和显式配置的 HTTPS 服务，拒绝 URL 凭据及非根地址。

运行测试：desktop 目录 `npm test`；前端构建与原生窗口端到端测试分别执行 frontend 的 build 和 desktop 测试文件。

## 使用

### 在另一台 Windows 电脑使用

只需网页陪伴时，直接打开云端工作台并登录即可。网页小狒会自动出现，支持拖动并记住位置、点击聊天、专注与休息联动、完成庆祝；3D 不可用时自动使用 2D。可在“个人账户 → 偏好设置”开关网页显示。

每台电脑需要先运行一次本地桌宠，注册 `xiaoqi-workbench` 启动协议。只打开网站不会安装桌宠。

需要桌面悬浮时，Windows 10/11 的 64 位电脑可使用 `小狒-Windows-x64-20261008-v2.zip` 便携包，内含 Electron 运行环境、2D 图集与 3D 模型依赖，不需要 Node.js、Python、Docker 或本地工作台服务。解压完整文件夹到固定位置，双击包内的 `启动小狒.cmd`，连接现有云端工作台。随后在浏览器登录自己的账号，点击“打开 Windows 桌宠”，允许启动并在小狒窗口确认账号绑定。每台电脑分别完成这一步；移动便携文件夹后需再次运行启动器更新协议路径。不要从压缩包内直接运行。

便携包不包含账号、密码或本机用户配置。若电脑不支持 3D 所需的 WebGL2，可在托盘菜单选择“版本 → 2D 原版”。

- 工作台左侧“小狒桌宠”进入桌宠中心（`/pet`），预览动作并打开桌面聊天；浏览器通过已注册的 Windows 协议打开本地程序。
- 点击小狒：打开聊天。拖动：移动位置，松开后轻轻落地。
- 悬停小狒：随机招手、伸懒腰、打哈欠或喝水，招手可使用左手或右手；持续悬停时隔几秒再回应，避免连续重复。移开后完成当前动作，不再继续触发；专注、休息、AI 状态、庆祝和漫步优先，静止模式不触发悬停动作。
- 左右拖动时，小狒跟随最近的水平移动方向转脸；垂直拖动或轻微抖动保持朝向，松开后先落地再恢复陪伴。
- 桌面窗口顶部“聊天 / 清单 / 专注”直接切换同一窗口中的页面；清单与专注采用适合窄窗口的布局，聊天草稿、附件、进行中的回复与专注/休息倒计时在切换后保留。专注支持选择或新建任务、自定义时长、暂停/继续、结束记录与短/长休息。
- 窗口、Windows 任务栏与托盘使用原版 2D 小狒图标，切换桌宠的 2D/3D 外观不会改变应用图标。
- 右键小狒或点击系统托盘：显示/隐藏、安静模式、大小、位置重置、聊天、工作台、设置、退出。
- 个人账户的桌宠设置：显示、置顶、动画、漫步和大小，立即生效。
- 版本保留“2D 原版 / 3D 立体”，可从桌宠中心、个人账户或右键/托盘菜单选择。桌面偏好保存后重启恢复，切换沿用大小、位置和状态联动；工作台预览同步切换。浏览器单独记住预览选择，点击“打开 Windows 桌宠”时通过启动链接应用已选择的版本。
- 专注时工作类显示打字，学习类显示读书；休息显示喝水/休息；AI 处理中显示思考，等待确认时提示打开聊天。
- 当前登录账号新完成任务时庆祝；网络断开、登录失效时停止状态联动。已绑定的桌面版失去显示许可后隐藏，恢复连接后重新交接；未绑定的独立桌面版保持原有陪伴行为。
- 网页自动启动：网页小狒默认开启，Windows 桌面自动启动默认关闭。可在网页“个人账户 → 偏好设置 → 小狒桌宠”分别设置“在网页显示小狒”与“打开网页时自动启动桌宠”；保留当前浏览器已保存的偏好。关闭桌面自动启动只停止本浏览器后续自动启动，已有账号绑定仍跟随账号切换。
- 网页换账号联动：首次打开时在小狒窗口确认“同步账号”一次；以后这个浏览器切换账号或退出都会同步。另一个浏览器或另一台电脑的登录不会改变这次绑定。
- 在桌宠窗口主动退出账号会断开绑定，网页仍保持登录；要重新联动，从网页再次打开桌宠并确认绑定。

## 边界

桌宠是本地桌面程序，需要连接运行中的工作台服务；便携版使用云端服务，无需在其他电脑部署后端。3D 版需要 WebGL2 图形支持；2D 版使用原始角色与动作图集，通过 Canvas 播放。桌宠可在聊天窗口隐藏或其他浏览器关闭时继续工作；退出托盘程序后停止。已提供 Windows 64 位便携包，尚未制作签名安装包。

## 快速拖动修复（2026-10-06）

拖动 IPC 改为携带按下、移动和松开时的屏幕坐标。后台不再以处理消息时的鼠标位置反推这次操作，避免快速拖动或后台消息延迟时起点与终点重合、桌宠完全不移动；松开时应用最终坐标并保存位置。取消捕获仍在当前位置结束拖动。
