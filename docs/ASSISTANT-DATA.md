# 在小狒对话中查询和导出个人资料

小狒可以按需查找当前登录账号的应用资料，包括账号和联系方式、任务（含隐藏任务和垃圾站）、日历安排、项目和依赖、周期规则和实例、专注、任务历史与快照、对话及已提取的附件文字、记忆、周报月报、偏好、公开模型配置、调用用量、资讯收藏和反馈、导入批次等。

可以直接说：

- “我的账号是什么？用的什么时区？”
- “查一下垃圾站里和面试有关的任务。”
- “找找我以前关于学习计划的对话。”
- “导出我的全部账号资料。”
- “把全部任务导出为 Excel，包含隐藏任务和垃圾站。”
- “导出本周周报。”
- “导出上周周报为 Word。”
- “导出上月月报为 PDF。”

任务明细和周报、月报支持 Excel、Word、PDF、CSV。完整账号资料使用 JSON，包含云端保存的应用资料和已处理的附件。设备本地界面偏好不属于云端账号资料；JSON 用于阅读和归档，不能直接作为现有任务导入格式使用。

生成文件卡片后，网页版点击“下载文件”；安卓点击“保存或分享”，在系统分享界面选择处理方式。卡片会保存在对话中，切换页面或刷新后仍可使用。任务资料和完整账号资料在下载时读取当前数据；周期报告读取对应的已保存报告，如再次生成同一周期，旧卡片会读取该周期更新后的报告。删除对话或遗忘相关来源后，卡片会清理或变得不可用。

周报按账号时区的周一至周日计算，月报按自然月计算。包含完成任务数、完成事件数、新增任务、专注时长、活跃天数、同期比较、实际完成清单和生成时的待结转任务；进行中的周期会注明未结束。专注时长归于专注开始日期。报告根据真实记录生成，不依赖模型编造统计。

查询只使用当前账号权限，不能指定另一个用户或执行任意 SQL。密码、密码哈希、API 密钥、登录和找回密码令牌、CSRF 凭据均不可读或导出。永久删除、主动遗忘的来源与派生资料不会通过新查询恢复。查询不会修改任务；现有任务写操作继续先预览、确认后执行。

助手按需分页查询，每页最多 50 条，每次消息最多 3 轮查询；长正文会注明节选。范围过大时可以指定类型、关键词和日期，或者导出完整资料。任务文件单次最多 10000 条，继承原有导出限制。

## 免费联网搜索

云端网页版输入框旁增加“联网搜索”开关，手机显示“联网”。默认关闭，开启后小狒按问题需要搜索公开网页，普通聊天及任务管理无需搜索。开关按账号记住，退出后清理。可以试“联网搜索 Python 官方文档，给我入口并简单介绍”。

首版使用 Bing 公开搜索 RSS，无需搜索密钥。每条消息最多两次搜索，每次最多五条结果；中文召回、结果相关性和可用性受免费入口限制，无结果时可换简洁或英文关键词。失败或空结果会明确说明，不代表网上不存在信息。搜索免费，对话模型处理搜索结果仍使用现有模型额度。

回答下方的网页来源来自服务器真实结果，可点击打开；切页、刷新和查看历史可恢复。回答基于搜索摘要，不代表阅读了网页全文。模型仅能引用已取得的来源编号，不能自行生成来源卡片。删除对话或遗忘相关来源后不再返回这些卡片。

只向预设搜索入口发送必要关键词，不提交整段对话、私人任务列表、附件或认证信息，不访问任意网页地址。搜索资料不授权任务变更，现有任务写操作继续由用户确认。本次发布未重新打包已有安卓 APK，联网入口在更新后的云端网页中使用。
