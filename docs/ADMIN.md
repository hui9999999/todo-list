# 管理后台

管理员登录后自动进入 `/admin`，左侧“管理后台”仅对管理员显示。普通账号的所有管理接口返回 403，未登录返回 401；写操作沿用来源与 CSRF 校验。

后台支持搜索、分页查看全部注册账号、注册时间、按日期统计输入/输出 Token 和调用次数，以及按用户查看模型汇总和最近 100 条调用记录。日期按各用户的账户时区计算。不选日期统计全部历史。Token 来自应用已记录的厂商返回值；未返回完整用量的调用单独标记，预留预算不会叠加到实际消耗。管理员没有读取其他用户任务、聊天原文、密码或模型 Key 的接口。

点击“查看用户”打开用户信息与用量图表：输入/输出 Token 趋势、输入/输出占比、各模型用量、调用用量报告状态。趋势按完整用量记录汇总，最近 100 条明细可以展开核对；缺少调用的日期补零，未报告的 Token 不估算为实际消耗。短时间范围按日展示，较长时间范围自动合并日期，并保留每个区间的准确起止日期与数值。无用量用户显示零值图表和空状态，手机端可在弹窗内滚动查看。

“AI 人设”管理全站助手的身份与交流风格，网页和桌宠共用，保存后用于后续聊天。任务权限、写入确认、附件可信度和数据隔离规则由平台保留。保存检查版本；遇到并发更新时保留草稿并提示重新读取。填入默认人设后仍需点击保存才生效。

## 创建管理员

数据库升级后，在 backend 目录执行 `.venv\Scripts\python.exe -m app.bootstrap_admin admin123`，按隐藏输入提示设置密码。该工具使用数据库维护权限，仅保存密码哈希；现有同名账号不会被覆盖。普通网页注册仍限邮箱或手机号，不能自行创建管理员或修改管理权限，应用数据库角色也没有写入 `users.is_admin` 的权限。

管理员与普通用户共用登录界面；输入管理员账号即可登录。不要将管理员密码写入代码、配置模板或启动参数。
