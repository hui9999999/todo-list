# 天气回答与旧垃圾站话题串联

用户报告：先问垃圾站，再问“今天天气怎么样”，小狒重复汇报垃圾站为空，猜测上海，并引用节假日等无关网页。

根因核对：垃圾站预读扫描最近六条消息中的任意垃圾站提及，未判断最新用户请求是否切换话题；天气走通用免费搜索 RSS，没有使用应用已有天气服务。受影响账户的天气城市配置实际为深圳。

修正：垃圾站仅在当前明确请求或继承该话题的简短追问时预读；最近明确用户话题优先于旧助手文本。模型指令限制回复最新请求。开启联网后，简单当前天气问题直接读取共享天气服务，未指定城市使用账户配置，明确指定城市只影响本次读取。实况包含城市、温度、观测时间和真实来源；模型不得把当前观测描述为全天或未来预报。天气来源单独标注“当前实况”，不标为搜索摘要。联网关闭、任务管理问题不发起助手天气请求，取消后不发布来源。

中国天气网实况先验证城市站号、温度及时间，偶发 HTTP 连接失败只重试一次；未找到或格式错误才进入既有备用服务。云端只读探测发现国内服务可用，海外备用连接可能失败。读取失败应如实说明，不用通用搜索的无关页面代替天气。

验证：原实现新增五条复现检查中四条失败；修正后 101 条后端回归、14 条桌面和手机界面检查通过，前端构建通过。补充上游连接重试检查后，天气与搜索 46 条检查通过。云端使用临时合成账号保留“看看垃圾站 → 垃圾站为空”历史再发天气问题，实际 API、worker 与配置模型验收通过：返回深圳天气实况来源，回复没有旧垃圾站话题或上海猜测，来源刷新恢复且没有任务变更。验收账号已清除，真实用户现有对话未改写。
