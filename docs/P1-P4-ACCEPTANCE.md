## 使用与边界

在设置中添加厂商连接、正确地域和 Key，获取目录或填写模型 ID，然后测试模型，再设置默认模型和思考模式。百炼中国／美国地域目录需要业务空间 ID；没有该 ID 时仍可手动测试模型。目录中的声明能力与实际探测结果分别保存，未知模型只在通过测试后启用对应能力，不隐式切换到其他厂商。

对话生成期间绑定已选择的连接、模型和思考模式。结构化响应完整校验后才发布澄清或提案；确认、任务变更、快照和结果在事务内提交。提案检查任务版本及记忆上下文版本；撤销遇到后续修改会拒绝覆盖。浏览器断线可以按事件序号继续，进程中断会明确失败，写操作不会自动重放。

近期上下文最多 20 条消息、约 24000 字符，单条最多 8000 字符；更早部分从最近 80 条消息中抽取用户原文节选，带来源消息、时间范围及内容版本，最多约 8000 字符。它是可核对的节选摘要，不是覆盖全部会话的模型摘要。原消息仍保留；遗忘来源立即从读取路径排除。长对话需要用户补充重要条件。

任务事实、历史与记忆按完整记录限制大小，未纳入数量明确提供给模型。历史关键词检索扫描时间窗内最近 5000 条事件，并提供当时快照；旧版缺少过程历史时不会补造。向量搜索默认使用系统提供的 `qwen3.7-text-embedding`，用户无需配置，后台按 20 条一批索引，准备中／失败时回到关键词。配置及真实联调记录见 [系统默认向量搜索](SYSTEM-EMBEDDING.md)。大量历史和向量负载尚未做性能压力测试。

资讯与工作建议默认关闭，首次开启从下一次当地设定时间开始。资讯源由管理员维护 `backend/article-sources.json`，用户任务正文不会发送给 RSS 源。选定模型生成资讯摘要时没有任务工具，URL 始终取自来源。没有足够相关内容时可以少推或不推。

今日建议每天至多 5 条，工作与生活分别保留范围；不读取外部日历。新增事项必须引用当前任务或有效的明确目标，调整必须使用来源任务的当前版本。新增任务和今日关联只在确认时一起创建。估时标注 AI 估算，容量未知时不声称掌握精确空闲时间。没有验证工具能力的模型时使用可说明的规则排序。

后台调用数与 Token 使用数据库原子预留；厂商返回用量时结算，未返回时保留保守预留并标记未知。主动对话、能力测试单独记录；设置中的每日保护额度约束后台资讯、建议、索引和语义查询，不代表厂商账单。单次对话／建议最多一次模型调用，输出和运行时间有上限。

独立 worker 执行队列、周期、遗忘和保留清理；每 45 秒续租长作业，进程停止后依靠到期租约恢复。到期通知属于页面打开时的浏览器通知，不是离线 Push。天气为主动开启的固定公共接口，未开启时不请求。当前已验证本地单 worker；多 worker 负载、长期运行和故障注入尚未作为正式运维验收。

JSON 备份用于任务、项目、依赖、事件与安排的账户级导入恢复，不包含密码、会话或模型凭据，也不是完整账户迁移包。完整服务器恢复使用数据库备份；Excel 为可阅读清单，不作为导入格式。

## 备份与发布准备

本地命令在 `backend` 目录执行：

```powershell
.venv/Scripts/python.exe -m app.backup backup --output .runtime/backups
.venv/Scripts/python.exe -m app.backup restore-drill --dump <备份路径> --journal <最新删除日志路径>
```

恢复演练只创建新隔离库，并保留它用于核验。数据库 dump 包含加密的厂商凭据；主密钥不包含在 dump 中，需要单独、受限保管 `CREDENTIAL_MASTER_KEY` 或 `.runtime/credential.key`。

独立 worker 将最小删除标记写入 `.runtime/deletion-journal.json`，不保存被删正文。**必须独立保管最新删除日志，恢复前重放最新日志；旧 dump 随附的旧日志不能保护备份之后的删除。** 应在放行访问前完成重放并撤销旧会话。生产环境还需配置备份频率、异地留存、恢复权限与定期演练；当前提供工具和本地演练，不包含托管备份服务。

生产入口为 `compose.production.yaml`、`production.env.example`、两个 Dockerfile 和 Caddy 配置。数据库、应用、只读发现角色分离，启用同源 HTTPS、Secure Cookie 和正式 TLS SMTP。示例文件是占位配置，未用于公开部署。

正式发布尚须：用户配置的 DeepSeek 与百炼真实账户端到端联调、域名 DNS／TLS 和正式邮件往返、生产镜像构建与健康检查、出站连接及实际计费核对、独立密钥／删除日志备份与生产恢复演练。缺少这些证据时，P1 的真实联调出口和 P4 的正式发布出口不标为完成。
